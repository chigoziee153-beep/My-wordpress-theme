# NYDLA Custom Theme Changelog

## 0.4.0 — Staging build (November 5, 2026)

- Preserved v3 Customizer controls and Gutenberg home blocks.
- Added native WordPress-managed two-column Explore mega dropdown, with support for nested groups (3 menu levels) and optional featured menu item.
- Added separate submenu toggle buttons for keyboard and touch navigation; preserved clickthrough destinations.
- Added compact sticky header with WordPress admin-bar offset.
- Added proposed Distance Learning → Digital Learning → Digital Living home copy as *new defaults*, without overwriting existing saved page content.
- Added a fully editable **NYDLA Brand Journey** dynamic Gutenberg block with Customizer fields for every stage.
- Added non-destructive display fallback for v3 Home pages and an optional v4 upgrade to insert the journey block and replace only exact, unchanged v3 sample text.
- Added pointer-following hero spotlight, refined card interactions, scroll-based journey progression, article reading progress, and animation-intensity controls.
- Added reduced-motion safeguards and responsive CSS for mobile/tablet.

## 0.3.0 — Previous staging build

- Rounded hero, Oswald/Jost typography, loading screen, fade-in/moving artwork, responsive navigation, and five editable Home blocks.

## 0.2.0 — Previous development build

- Expanded Customizer fields, page editing, colors and native menus.

## 0.1.0 — Initial foundation

- Original WordPress theme framework, homepage, header, cards, membership panel, articles and footer.
